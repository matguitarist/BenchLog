# 72-Pin Connector Replacement

## Overview
The 72-pin connector is often considered the Achilles' heel of the original front-loading NES. This component connects the motherboard to the game cartridges and is responsible for many common issues, including the blinking red light problem. Replacing this connector is one of the most effective repairs for a malfunctioning NES.


![[72_pins_connectors.png]]


## When to Replace the 72-Pin Connector
Consider replacement when:
- Cleaning and adjusting the original connector doesn't resolve issues
- Games consistently fail to load (blinking light)
- The connector has visible damage or severe corrosion
- Games only work after multiple insertion attempts
- The connector has extremely loose or tight cartridge grip

## Required Tools
- Phillips screwdriver
- Flathead screwdriver (small)
- Replacement 72-pin connector
- Isopropyl alcohol (90%+ concentration)
- Cotton swabs
- Anti-static wrist strap (recommended)
- Small container for screws
- Needle-nose pliers (optional)

## Replacement Options
There are several types of replacement connectors available:

1. **Original Used Nintendo Connectors**: Pulled from donor NES consoles, may have similar wear issues but can be cleaned
2. **Third-Party Reproductions**: Quality varies significantly between manufacturers
3. **"Blinking Light Win" (BLW)**: Premium replacement that eliminates the need for the spring-loaded cartridge tray
4. **"Gold-plated" Connectors**: Marketing claim, quality depends on manufacturer

## Step-by-Step Replacement Procedure

### Step 1: Prepare the Console
1. Unplug all cables from the NES
2. Work in a clean, well-lit area
3. Place the NES on a soft surface to prevent scratches
4. Consider using an anti-static wrist strap to prevent ESD damage

### Step 2: Open the NES Case
1. Turn the NES upside down
2. Remove the six Phillips screws from the bottom of the case
3. Turn the NES right-side up
4. Carefully lift the top half of the case off
5. Set the top case aside

![[open_nes_case.jpg]]

### Step 3: Remove the RF Shield
1. Locate the metal RF shield covering the motherboard
2. Remove the seven screws securing it
3. Lift off the RF shield and set aside
4. Note: Some models may have a second shield on the bottom that can remain in place

![[rf_shield_removal.jpg]]

### Step 4: Disconnect Internal Cables
1. Locate the power/reset and controller port ribbon cables
2. Note their orientation (take a photo if needed)
3. Gently disconnect these cables from the motherboard
4. Be careful not to tear or damage the ribbon cables

![[ribbon_cable_disconnection.jpg]]

### Step 5: Remove the Cartridge Loading Mechanism
1. Locate the four screws holding the cartridge loader assembly
2. Remove these screws and set aside
3. Carefully lift out the entire cartridge loading mechanism
4. The tray, springs, and other components should stay together as one unit

![[cartridge_loader_removal.jpg]]

### Step 6: Remove the Original 72-Pin Connector
1. The 72-pin connector sits between the cartridge loader and motherboard
2. Carefully pull upward to separate it from the motherboard pins
3. It should slide off the 72 pins on the motherboard
4. If stuck, gently rock it back and forth while pulling upward
5. Do not bend the pins on the motherboard!

![[original_connector_removal.jpg]]

### Step 7: Inspect the Motherboard Connector
1. Examine the 72 pins on the motherboard
2. Look for:
   - Bent pins
   - Corrosion
   - Damage
3. If pins are bent, carefully straighten with needle-nose pliers
4. Clean the pins with isopropyl alcohol if needed

![[motherboard_pins.jpg]]

### Step 8: Install the New 72-Pin Connector
1. Align the new connector with the pins on the motherboard
2. The connector should only fit one way (notched end toward the back)
3. Press down firmly and evenly until fully seated
4. Make sure all pins are properly engaged

![[new_connector_installation.jpg]]

### Step 9: Reassemble the Console
1. Place the cartridge loading mechanism back in position
2. Reinstall the four screws to secure it
3. Reconnect the ribbon cables
4. Replace the RF shield and secure with seven screws
5. Position the top case and secure with six screws on the bottom

![[reassembly.jpg]]

## Testing After Replacement
1. Connect the NES to power and TV
2. Insert a known working game cartridge
3. Power on the console
4. The game should start without blinking light issues
5. Test several different games if available
6. Try various insertion techniques if problems persist

## Troubleshooting Post-Replacement Issues

### Still Having Blinking Light Issues?
1. Ensure the connector is properly seated on all pins
2. Clean the game cartridges thoroughly
3. Try disabling the lockout chip (see [[blinking-red-light|Blinking Red Light]] guide)
4. The replacement connector might be of poor quality, consider another brand

### Games Not Inserting Properly?
1. Some third-party connectors have tighter grip than original
2. Game cartridges may need extra cleaning
3. If too tight, consider gently loosening the pins
4. If too loose, you may have received a poor-quality replacement

### Games Start But Freeze or Glitch?
1. Clean the game cartridge contacts again
2. Check for proper seating of the connector
3. Ensure no bent pins on the motherboard
4. Try the game on another system if possible

![[troubleshooting_chart.jpg]]

## Blinking Light Win (BLW) Installation
If using the premium BLW replacement:
1. The installation differs slightly from standard replacements
2. Follow the included instructions
3. The cartridge tray is modified to remain in the "down" position
4. This eliminates the wear caused by the up/down mechanism

![[blw_installation.jpg]]

## Maintenance After Replacement
1. Clean game cartridges before use
2. Insert and remove cartridges gently
3. Don't leave games inserted when not in use
4. Keep the console dust-free
5. The new connector should last many years with proper care
