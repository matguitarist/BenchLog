## Tools Needed
- Phillips screwdriver
- Security bit screwdriver (3.8mm gamebit for NES cartridges)
- Flathead screwdriver (small)
- Cotton swabs
- Isopropyl alcohol (90%+ concentration)
- Compressed air
- Electrical contact cleaner
- Brass/copper polish (for cartridge contacts)
- Soldering iron and solder (for advanced repairs)
- Multimeter
- Needle-nose pliers
- White vinegar or hydrogen peroxide (for cleaning)

## Safety Warnings
- Always unplug the NES before opening or servicing
- Discharge any static electricity before handling components
- The power supply contains high-voltage capacitors that can hold charge even when unplugged
- Keep cleaning solutions away from electronic components unless specifically directed

## NES Identification
There are two major versions of the NES console:
- **Original "toaster" NES (NES-001)**: The original front-loading design
- **Top-loading NES (NES-101)**: The redesigned top-loading model released later

This guide primarily covers the original front-loading model, as it's more common and prone to more issues. Check the [[nes-model-identification|NES Model Identification]] guide to determine which version you have before beginning repairs.

## Maintenance Recommendations
Even if your NES is working properly, consider performing these recommended maintenance procedures:
- Clean the 72-pin connector
- Clean cartridge contacts
- Disable the lockout chip (CIC) if experiencing frequent issues
- Clean the console thoroughly
- Replace corroded battery contacts in controllers
