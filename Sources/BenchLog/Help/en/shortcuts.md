# Keyboard Shortcuts

## Anywhere

| Shortcut | Does |
| --- | --- |
| ⌘N | New Repair |
| ⇧⌘N | New Customer |
| ⌥⌘N | New Counter Sale |
| ⇧⌘D | Add Device to the customer |
| ⌘F | Search BenchLog |
| ⌥⌘1 to ⌥⌘9 | Go to a sidebar page |
| ⌘[ and ⌘] | Back and Forward |
| ⌘, | Settings |
| ⌘? | BenchLog Help |

## On a repair

| Shortcut | Does |
| --- | --- |
| ⌘1 to ⌘8 | Set the status, from Intake to Cancelled |
| ⌘P | Print Intake Slip |
| ⇧⌘I | Invoice |
| ⇧⌘K | Add Note |
| ⇧⌘P | Add Photo or File |
| ⌥⌘P | Show or Hide Passcode |
| ⌘⌫ | Move to Trash |
| ⌘Z | Undo |

## In a guide

| Shortcut | Does |
| --- | --- |
| ⌘F | Find in Guide |
| ⌘G and ⇧⌘G | Next and previous match |
| ⌘+, ⌘−, ⌘0 | Zoom in, zoom out, actual size |
