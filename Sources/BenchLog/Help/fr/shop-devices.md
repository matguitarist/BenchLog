# Appareils de l’atelier

Certains appareils appartiennent à l’atelier : une console achetée pour la réparer et la revendre, un téléphone gardé pour les pièces.

1. Dans la page **Appareils**, choisissez **Ajouter un appareil de l’atelier…** et entrez ce que vous l’avez payé.
2. Les réparations d’un appareil de l’atelier sont **internes** : ni bon de dépôt, ni estimation, ni facture, et le dernier statut est *Terminé*. Les pièces installées s’ajoutent à son coût.
3. Indiquez ce qu’il est devenu : **En stock**, **À vendre**, **Gardé** ou **Vendu**.
4. Une fois vendu, entrez le prix. BenchLog montre le **profit** ou la **perte**, et **Facturer la vente** le facture à l’acheteur avec les taxes.
