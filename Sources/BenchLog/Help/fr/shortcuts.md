# Raccourcis clavier

## Partout

| Raccourci | Action |
| --- | --- |
| ⌘N | Nouvelle réparation |
| ⇧⌘N | Nouveau client |
| ⌥⌘N | Nouvelle vente au comptoir |
| ⇧⌘D | Ajouter un appareil au client |
| ⌘F | Rechercher dans BenchLog |
| ⌥⌘1 à ⌥⌘7 | Aller à une page de la barre latérale |
| ⌘[ et ⌘] | Précédent et Suivant |
| ⌘, | Réglages |
| ⌘? | Aide BenchLog |

## Dans une réparation

| Raccourci | Action |
| --- | --- |
| ⌘1 à ⌘8 | Changer le statut, de Reçue à Annulée |
| ⌘P | Imprimer le bon de dépôt |
| ⇧⌘I | Facturer |
| ⇧⌘K | Ajouter une note |
| ⇧⌘P | Ajouter une photo ou un fichier |
| ⌥⌘P | Afficher ou masquer le code |
| ⌘⌫ | Placer dans la corbeille |
| ⌘Z | Annuler |

## Dans un guide

| Raccourci | Action |
| --- | --- |
| ⌘F | Rechercher dans le guide |
| ⌘G et ⇧⌘G | Résultat suivant et précédent |
| ⌘+, ⌘−, ⌘0 | Agrandir, réduire, taille réelle |
