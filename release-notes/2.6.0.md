## The same Help menu as every app

- **What's New in BenchLog** opens the latest release notes.
- **Report a Problem…** opens a new GitHub issue with the app version, build and macOS version already filled in.
- **Check for Updates…** is always in the BenchLog menu, greyed out when updates aren't available.
- **BenchLog on GitHub** and **Show Log** are in the Help menu.
