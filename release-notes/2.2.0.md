BenchLog 2.2: this Mac can be the shop server.

- **Use This Mac as the Server** (Settings > Sync): BenchLog runs its own server on a Mac that stays on in the shop. No Docker, no Node. It keeps running when BenchLog is closed and after a restart.
- Settings shows what the other Macs enter, the address and the token, each with **Copy**.
- While it serves, the Mac does not go to sleep on its own. **Stop Using This Mac as the Server…** stops it; its data stays.
- The server on a NAS (Docker) still works, and opens the same data folder.

BenchLog 2.2 : ce Mac peut être le serveur de l’atelier.

- **Utiliser ce Mac comme serveur** (Réglages > Synchro) : BenchLog fait tourner son propre serveur sur un Mac qui reste allumé à l’atelier. Ni Docker, ni Node. Il continue de tourner quand BenchLog est fermé et après un redémarrage.
- Les réglages montrent ce que les autres Mac entrent, l’adresse et le jeton, chacun avec **Copier**.
- Tant qu’il sert, le Mac ne se met pas en veille de lui-même. **Ne plus utiliser ce Mac comme serveur…** l’arrête ; ses données restent.
- Le serveur sur un NAS (Docker) fonctionne toujours, et ouvre le même dossier de données.
