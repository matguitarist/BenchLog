BenchLog 2.1: help for every job, and Settings one click away.

- **BenchLog Help** (⌘?): a Help window with a topic for each job, from checking a device in to setting up the shop server, with a list of keyboard shortcuts. Search narrows the topics.
- **Help menu**: Keyboard Shortcuts, Set Up the Shop Server, What's New in BenchLog, and Report a Problem.
- **Settings** has a button at the bottom of the sidebar; the sync status beside it is shorter, so it fits.
- **Fixed**: the BenchLog server's Docker image stopped at start; it now writes its data folder. The server README explains how to keep the data in a folder of your own on a NAS.

BenchLog 2.1 : de l’aide pour chaque tâche, et les réglages à un clic.

- **Aide BenchLog** (⌘?) : une fenêtre d’aide avec un sujet pour chaque tâche, de la réception d’un appareil à l’installation du serveur d’atelier, avec la liste des raccourcis clavier. La recherche filtre les sujets.
- **Menu Aide** : Raccourcis clavier, Installer le serveur d’atelier, Nouveautés de BenchLog et Signaler un problème.
- **Réglages** : un bouton au bas de la barre latérale; l’état de la synchro à côté est plus court, pour tenir.
- **Corrigé** : l’image Docker du serveur BenchLog s’arrêtait au démarrage; elle écrit maintenant son dossier de données. Le README du serveur explique comment garder les données dans votre propre dossier sur un NAS.
